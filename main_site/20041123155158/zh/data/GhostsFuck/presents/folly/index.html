距离都市稍远的安静街区。
除了中心高台上的学校，这个没有什么特别之处的街区发生了一件怪事。
十三年前，一个男人在这条街上被杀害了。
这是一件用刀具乱砍乱杀、极其残酷的事件，当时受到了媒体和世人的关注。
尽管警方进行了彻底的搜查，但猎奇事件的犯人始终未能抓获。
过了一年社会就淡忘了，三年后媒体也忘却了。
就这样，十三年过去了，正当人们以为街区恢复了平静时，
怪奇事件再次发生。
只以学生为目标频繁发生的无差别伤人事件。
就读于街上唯一一所私立学校的学生奥山时雨，与幕后情报贩子坂上叶月一起开始调查这个事件。
不久，两人察觉到了这与曾经的猎奇杀人事件的关联。
随着事件的发展，被称为〈执行者〉的拥有超常力量的人们逐渐浮出水面。
就在这时，
在平时学校生活中从不与人深交的时雨，
唯一敞开心扉的一位少女被卷入了事件。
曾是十三年前事件关系人的时雨离开叶月身边，独自行动，但是——
「杀或不杀，这种事情无所谓吧？
无论是活着还是死了，到处都有差不多的家伙。
——我也，是那样的。」




　奥山 时雨　１７　　♂

私立夕樱学园的二年级学生。十三年前发生的杀人事件的关系人。
出身于名为奥山家的古老名门，但因故离家出走，过着寄人篱下的生活。帮忙做寄宿处坂上叶月的工作。
十三年前觉醒了〈执行力〉，现在这个名字在〈执行者〉之间广为人知，伴随着敬畏。
从小就被灌输古流剑术和武术，其身手足以轻易对付二三流的格斗家。

虽然带有情绪不稳定的多面性，但本质率直、认生。
戴着平光眼镜，基本上态度冷淡。在学校也不放下刀包的、有点难以接近的人。
在同学面前扮演着不可思议的男人，但本质上总是感到虚无。
因此，基本上不参加班级的团体活动。


　一条 彩　１７　　♀

夕樱学园的二年级学生。和时雨不同班的朋友。虽然只是在天台上与时雨一起无所事事地聊天。应该算这样的关系，
但以彩开始在坂上叶月经营的咖啡店〈Fronde・Londe〉打工为契机，
从认识程度的关系变成了更进一步的朋友。
由于连续发生的无差别伤人事件中的某个事件，得以一窥时雨作为〈执行者〉的一面。
同时，也知道了叶月本来的工作，不久后开始帮她们做一些事情。

天才型学生，运动稍微有点不擅长。齐肩长发束在脑后，平时戴隐形眼镜。
班级里沉着冷静的班长。认真、待人接物也好，因此在班级里受到信赖。
说是细腻，直说就是容易受伤的一面。


　　坂上 叶月　２８　　♀

咖啡店〈Fronde・Londe〉的老板。是极少数知道十三年前事件真相的人物之一。
与从事件以来一直照顾时雨的人是熟人，以此为理由让时雨寄住。
一边经营咖啡店，一边还拥有知名情报贩子的面孔。
不仅仅是单纯处理信息的工作，关于〈执行者〉关系的情报，她会亲自把时雨当作代理人行动起来。
过去，在〈执行者〉相关事件中失去过一个弟弟。是个留着长长黑发、让人感到寒意、美得不可方物，
但性格破绽又重度吸烟的美人。对时尚几乎完全不感兴趣，每天都穿着近乎相同的衣服。
尽管如此，家务却完美得无可挑剔。与奇葩仅一步之遥的、真正的天才。


　奥山 启吾　３５　　　♂

时雨的养父。在十三年前的事件中救下时雨的人。
曾与叶月交往过一段时间，因此将时雨托付给她。本人目前下落不明。
听说会定期联系叶月……。

面容清秀的美男子。就是他教会时雨一般武术的。有着恐怖的武艺。
时雨别说赢他一次，玩闹之外，连一击都没能击中过他。
时雨的理想型。平时是个沉静而充满哲学气息的人。五官纤细，老实说，是神创造的最高杰作。
因为本人没有意识到，所以误解也很多。




「咕、呕噗。」
伴着含糊的呻吟声，胃里的内容物被豪爽地吐在路上的声音响起。
「喂、你……真的是高中生吗……？」
在昏暗电灯那微弱的灯光下，靠在墙上的影子和坐在路上的影子两个轮廓模模糊糊地浮现出来。
「你已经明白了吧。就凭你是不能拿我怎样的。」
年轻，听起来还像是高中生的青年声音，却有着与年龄不相符的、令人感到冰冷彻骨的语调。那是在日常生活的普通人绝不可能体验到的修罗场、而且是关乎性命的修罗场中摸爬滚打过来的人才能发出的声音。虽然蹲着的男人也没有因此被完全压倒，但颤抖的声音证明了其受到了威压。
「不想再碰到这种倒霉事的话，就立刻给我离开这个镇子。　下次再在镇上看到你，到时候——我就杀了你。」
「到此为止吧，时雨。」
意想不到地掺入了第三者的声音。正好位于死胡同的入口处，也就是青年的后方。能让人联想到冷静的女性那略带沙哑的声音。咯噔咯噔的靴子踩踏沥青的声音渐渐靠近，不久，女性在青年身边站定。
「打算现在就杀了他吗？时雨。那家伙已经晕过去了哦。」
即使听到女人不像女人的话语，被称为时雨的青年也没有动摇。挠着后脑勺厌烦地反驳道。
「最近啊，持有〈执行力〉的家伙增加了。而且净是些好像刚觉醒一样的家伙。所以想在日常生活中随意使用力量。没什么情报钓上来吗？」
「还没得到。不知是怎么回事，大家似乎都混乱了。从平时的老熟人那里进货，准确性也不够。」
冷静之中渗透出些许懊悔。青年已经朝着巷子外面走去，将细长的包裹扛在肩上，大大地吐了口气。
「算了，也好。反正不管早晚。这些家伙，是组织，八成。而且规模还挺大。」
「组织呢。虽然〈执行者〉不会有那么多，但留点神总是好的吧。刚才那个是〈执行者〉？」
「嗯。只是，我只能感觉到非常微弱的能力。感觉像是后天附加上去的，并不熟练。」
「附加上的？还真是奇怪的家伙。〈执行者〉竟然不是被力量摆布，而是好像用不熟练？看来不是单纯的乌合之众啊。」

女人将单手拿着的、也不怎么抽的香烟扔掉，用靴底踩灭，然后以比青年更快的步伐走了起来。正值梅雨刚过，昨日的雨水湿气导致闷热难耐。大概是这个原因，青年和女人谁也没有遇见，并肩走在夜路上。因为是连垃圾都不用的死胡同，那晕倒的男人被发现，恐怕需要相当长的时间吧。
(摘自序章)
