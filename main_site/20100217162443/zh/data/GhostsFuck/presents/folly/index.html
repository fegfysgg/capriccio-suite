离都市稍远的宁静街区。
除了中心位于高台的学校，没有什么特别之处的街区，发生的奇妙事件。
十三年前，这条街上一个男人被杀害了。
被刀具乱刀砍死，是极其残虐的事件，当时吸引了媒体和世间的关注。
尽管警方拼命搜查，这个猎奇事件的犯人始终未被抓获。
过了一年，世间就遗忘了，三年后，连媒体也忘却了。
就这样，未解决的状态下过去了十三年，在看似恢复平静的街区，
再次发生怪奇事件。
只避开学生多发的抢劫伤人事件。
就读于街上唯一一所私立学校的奥山时雨，与背后营生的情报屋坂上叶月一起，开始调查这起事件。
不久，两人察觉到了与过去的猎奇杀人事件的关联。
随着事件的进展，拥有被称为〈执行者〉的超常能力的人们变得明确。
就在那时，
在平时的学校生活中绝不与人深交的时雨，
唯一敞开心扉的少女，被卷入了事件。
作为十三年前事件相关者的时雨，离开了叶月，开始独自行动，但是——
“杀与不杀，这种事情无所谓吧？
活着还是死了，都有一大堆同样的家伙。
——我也是，就那么回事。”




　奥山 时雨　１７　　♂

私立夕(sek)樱(ou)学园的二年级学生。十三年前发生的杀人事件的相关者。
出身于奥山家这个古老的名门，但由于种种原因离家，现在寄人篱下。在寄宿处的坂上叶月那里帮忙工作。
十三年前觉醒了〈执行力〉，如今这个名字在〈执行者〉之间，伴随着敬畏广为人知。
自幼被灌输古流剑术和同武术，身手精湛到一般的格斗家无法与之匹敌。

虽然带有几分情绪不稳定的面向，但根性是坦率且怕生的类型。
戴着平光眼镜，基本不爱说话。在学校也总是不离刀的包裹，是个有点难以接近的人。
虽然在同学面前扮演着不可思议的男人的角色，但本质上总是感到虚无感。
因此，几乎不参与班级的团体作业。


　一条 彩　１７　　♀

夕樱学园的二年级学生。与时雨不同班级的朋友。但只是在屋顶与时雨闲聊的关系。 应该是的，但是，
以彩开始在坂上叶月经营的咖啡店〈Fronde Ronde〉打工为契机，
从认识程度的关系发展成了更进一步的朋友。
由于接连发生的抢劫伤人事件中的某个事件，她得以窥见时雨作为〈执行者〉的一面。
同时，也知道了叶月原本的工作，不久便开始帮她们做事。

是天资聪颖的学生，不擅长运动。及肩的头发在后面扎起来，平时戴隐形眼镜。
在班级里是沉着冷静的班长。认真且待人随和，在班级里深受信赖。
说是纤细，说得直白点，就是脆弱的一面。


　坂上 叶月　２８　　♀

咖啡〈Fronde Ronde〉的老板。知道十三年前事件真相的少数人物之一。
自事件以来，与照顾时雨的人有交情，以此为借口让时雨寄居。
经营咖啡店的同时，背后也拥有名声响亮的情报屋的面孔。
从只是处理信息的工作开始，在涉及〈执行者〉的信息方面，有时会以时雨为特工亲自行动。
过去，在〈执行者〉相关事件中失去了一位弟弟。留着长长黑发，让人感到寒意袭来的美人，
但性格有缺陷，是个重度吸烟者。对时尚几乎完全不感兴趣，每天都穿差不多的衣服。
尽管如此，家务事却能完美地完成。是与怪人仅一纸之隔的真正的天才。


　奥山 启吾　３５　　　♂

时雨的养父。在十三年前的事件中救了时雨的人。
曾与叶月交往过一段时间，将时雨托付给她。本人目前行踪不明。
据说会定期联系叶月……。

脸庞清秀的美男子。时雨的武术全是这个人教的。恐怖的武术实力。
别说赢这个人一次了，时雨除了玩闹之外，连一击都未能打中他。
是时雨的理想形态的人。平时沉着冷静、富有哲理的人物。五官精致，简直可以说是神创造出的最高杰作。
本人没有意识到，所以也常被误解。




“咕、呕噗。”
伴随着含糊的呻吟声，胃里的内容物被大声吐在路上的声音响起。
“你、你这家伙……真的是高中生吗……？”
在昏暗的路灯那不足的灯光下，靠着墙壁的影子和蹲坐在路上的影子，两个朦胧地浮现出来。
“已经明白了吧。你不是我的对手。”
年轻，听起来还只是高中生年纪的青年的声音，与年龄不符，带着冰冷刺骨的感觉。如果不是经历过日常生活中的普通人绝对无法体验的修罗场，而且还是危及生命的那种，是无法发出这种声音的。蹲着的男人想必也不是被此压倒的吧，即使如此，他颤抖的声音证明了他被震慑住了。
“不想再遇到这种事儿，就赶紧滚出这条街。　下次再让我在这条街上看到你，那时——就杀了你。”
“到此为止吧，时雨。”
不意间混入了第三者的声音。正好是死胡同的入口处，也就是青年的身后。是让人联想到冷静的，沙哑的女性的声音。靴子喀喀地踩着沥青路面的声音接近过来，不久，女性在青年身边停下了脚步。
“打算现在就杀了他？时雨。那家伙已经昏过去了哦。”
对于女性这不像是女性该说的台词，被称为时雨的青年也没有动摇。搔着后脑勺，厌烦地反驳道。
“最近在增加啊。拥有〈执行力〉的家伙们。而且净是些好像是新人一样的家伙。打算在普通的日常生活中使用力量。没什么情报吗？”
“还没收到。不知为何，大家都在混乱。从常联系的老熟人那里也搞不到准确的情报。”
冷静中透出一丝懊悔。已经走向胡同外面的青年，将细长的包裹扛在肩上，大大地吐了口气。
“算了，无所谓了。不管怎样，不过是早晚的区别。这些家伙，是组织，多半。而且规模还不小。”
“组织啊。虽说〈执行者〉不会有那么多，但还是注意一下为好。刚才那家伙是〈执行者〉吗？”
“嗯。不过，只感觉到非常微弱的能力。好像完全无法驾驭，就像后来才安装上去的一样。”
“像是安装上去的？真是奇怪的说法。明明是〈执行者〉，却不是被能力玩弄，而是无法驾驭它，听起来不像单纯的乌合之众啊。”

女性将手里只是拿着却没吸的香烟扔掉，用靴底踩灭，以比青年更快的步伐走了起来。刚出梅雨季的这个时期，昨天为止的雨带来的湿气使得天气异常闷热。大概是因为这个原因，青年和女性走在夜路上，谁也没有遇到。因为是不像会用来扔垃圾的胡同，那个昏过去的男人被发现，恐怕需要相当长的时间。
